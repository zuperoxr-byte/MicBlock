# MicBlock
Blocks all data packets related to microsoft.

We will use Powershell script(s) for blocking all data going from Computer to Microsoft.
Microsoft uses data from out PCs to train data models, personalize ads, etc., and some people like me care about privacy,
that's why we made MicBlock (Microsoft Block).
You install an app on your Router and Device, and it pairs them both to BLOCK all Microsoft data going in and out.

For the people who can't/ don't want to switch to Linux.
